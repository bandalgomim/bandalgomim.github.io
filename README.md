# 개인정보 처리방침 / Privacy Policy

ALL'ts(이하 "앱")는 사용자의 개인정보 보호를 중요하게 생각하며, 아래와 같이 개인정보를 수집·이용합니다.  
ALL'ts ("the App") values your privacy and collects and uses personal information as outlined below.

---

## 1. 수집하는 개인정보 항목 / Information We Collect

앱은 다음과 같은 정보를 수집합니다:  
The app collects the following personal information:

- 이메일 주소: 사용자 식별 및 계정 관리  
  Email address: For user identification and account management

- FCM 토큰: 푸시 알림 발송  
  FCM token: For sending push notifications

- 프로필 이미지 (사용자 아이콘) 및 사용자가 선택한 팀 아이콘 이미지: 사용자 계정 및 팀 커스터마이징 시각화  
  Profile image (user icon) and user-selected team icon image: For visually representing the user's account and team customization

---

## 2. 개인정보 이용 목적 / Purpose of Use

수집한 개인정보는 다음의 목적에만 사용됩니다:  
The collected personal information is used solely for the following purposes:

- 로그인 및 사용자 인증  
  User login and authentication

- 푸시 알림 서비스 제공  
  Providing push notification services

- 사용자 프로필 표시  
  Displaying user profile

---

## 3. 개인정보 보관 및 파기 / Data Retention and Deletion

- 수집된 정보는 사용자 탈퇴 시 즉시 삭제됩니다.  
  All collected data is deleted immediately upon user account deletion.

- 별도 저장 없이 앱 운영 목적에 한하여 사용됩니다.  
  The data is used only for operational purposes and is not stored separately.

- 수집된 이미지 파일은 사용자 계정 삭제 또는 팀 아이콘 변경 시 즉시 삭제됩니다.  
  All user-selected images are deleted immediately when the user account is deleted or when the team icon is changed.

---

## 4. 개인정보 제3자 제공 / Sharing with Third Parties

- 앱은 개인정보를 어떠한 외부 기관에도 제공하지 않습니다.  
  The app does not share personal information with any third parties.

---

## 5. 이용자의 권리 / User Rights

- 사용자는 언제든지 앱 내 설정 또는 문의를 통해 개인정보 삭제를 요청할 수 있습니다.  
  Users may request deletion of their personal information at any time through in-app settings or by contacting us.
